# ESP32-S3 Firmware Guidelines

Xem chi tiết quy định và cấu hình tại file [AGENTS.md](file:///home/quanghaictu/OUT_SRC/PUMP_MY_FAMILY/AGENTS.md).

- **Hardware Target:** ESP32-S3 (Octal Flash / PSRAM N8R8 / N16R8)
- **Framework:** ESP-IDF v5.3+
- **Environment activation:** `get_idf` (hoặc `. $HOME/esp/esp-idf/export.sh`)
- **Build & Flash:** `cd my_esp32s3_app && idf.py build flash monitor`
